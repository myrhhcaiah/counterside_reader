# プロジェクトロードマップ

**カウンターサイド**のデータ作業は、目に見えない部分での膨大な工数を要します。実際のゲーム要素が表示されるまで、復号化やライブラリ管理が作業の大部分を占めており、キャラクタースプライトの描画だけでも大きな挑戦でした。そのため、本プロジェクトにはいくつかの制限があることをご了承ください。

実装しない／できない機能：
- タッチボイス / 戦闘ボイス。これを実現するには50,000ものファイルを整理し、アニメーションと同期させる必要があります。さらに全体のファイルサイズが15GBも増加してしまうため、配布がほぼ不可能になります。
- その他のグラフィック / オーディオアセット。上記と同様の理由です。
- 壊れたSpineアニメーションの修正。オリジナルのゲームファイルには、様々なSpineビューアーと互換性のないものが多く含まれています。Counter:Side Reader以外の外部アプリで動作させたい場合は、ご自身で解決していただく必要があります。
- 複合Spineアニメーション / VFX。背景や爆発などの表現において、他のアニメーションやエフェクトを組み合わせて構成されているものが多数存在します。これらを正しく動作させるためのタイミングやスケーリング、その他の例外処理を把握することは現実的ではありません。元のコードを再実装したり、それぞれのアニメーションをデバッグする余裕（リソース）がないためです。
- 追加言語のサポート。本アプリはオリジナル言語である英語・韓国語・日本語・繁体字中国語をサポートしており、これら全てを正しく処理するだけでも既に多大な労力が費やされています。

### 今後の予定
本プロジェクトはほぼ完成しており、今後はバグ修正のみを予定しているとお考えください。  
当初はプロジェクトのオープンソース化も検討していましたが、かなり難解な補助スクリプト群が多数存在しており、ゲームのサービスが終了していることを考慮すると、今からそれらを整理し直す価値はないと判断しました。  
Counter:Sideの内部データ（中身）をいじりたい方のために、[.lua復号スクリプト](https://gist.github.com/myrhhcaiah/ce200e7f88e60ef957e41335262b36fb)を公開しておきます。
